# Sitio web institucional — Institución Educativa Betania

## Qué incluye
- Menú horizontal solicitado y versión móvil.
- Accesibilidad: navegación por teclado, foco visible, contraste, tamaño de letra, textos alternativos y estructura semántica.
- Páginas de transparencia, atención ciudadana, políticas, mapa del sitio y búsqueda local.
- Formulario PQRSD de interfaz con campos mínimos, validaciones y modo anónimo.
- `robots.txt`, `sitemap.xml`, metadatos SEO, datos estructurados y página 404.

## Antes de publicar oficialmente
1. Reemplazar el Escudo oficial por el oficial y validar colores/manual de identidad.
2. Completar dirección, teléfonos, correos, horarios, responsables y redes sociales.
3. Cargar misión, visión, historia, sedes y documentos exactamente como estén aprobados.
4. Conectar PQRSD a un backend seguro con radicado, acuse, seguimiento, archivo, notificaciones y control de plazos.
5. Contratar dominio y alojamiento con HTTPS, copias de seguridad, monitoreo y cabeceras de seguridad.
6. Aprobar jurídicamente políticas de privacidad, términos, derechos de autor y accesibilidad.
7. Hacer auditoría WCAG 2.1 AA manual y automática; revisar también cada PDF, imagen y video.
8. Definir gobierno de contenidos: responsables, periodicidad, archivo histórico y protocolo de publicación.
9. Actualizar todas las URL de `https://www.iebetania.edu.co/` si el dominio final es diferente.
10. No publicar datos personales o imágenes de estudiantes sin base jurídica, autorización y medidas de protección.

## Publicación de prueba
Puede subir esta carpeta a GitHub Pages para demostración. Para operación oficial con PQRSD y cabeceras de seguridad se recomienda un alojamiento administrado con backend y soporte institucional.
